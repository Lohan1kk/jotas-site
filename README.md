# Jota's Bar e Restaurante — site

Marketing site for **Jota's Bar e Restaurante** (Liberdade, São Paulo).

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand assets

Photos and menus live under `public/brand/` (fachada, cardápios, jogo americano).
